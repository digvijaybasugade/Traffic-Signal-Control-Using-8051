# 🚦 Traffic Signal Control System Using 8051

## 📌 Project Overview

This project demonstrates a Traffic Signal Control System using the 8051 Microcontroller.

The program was developed using Keil, and the circuit was designed and simulated using Proteus.

## 🛠️ Technologies and Tools Used

* Microcontroller: 8051
* Programming Language: Embedded C
* Programming Software: Keil
* Circuit Design and Simulation: Proteus

## ⚙️ Working

The system controls the traffic lights in a predefined sequence:

1. 🔴 Red Light
2. 🟢 Green Light
3. 🟡 Yellow Light

The sequence continuously repeats to simulate the operation of a basic traffic signal control system.
